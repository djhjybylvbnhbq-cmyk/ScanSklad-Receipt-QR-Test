ScanSklad Receipt + QR TEST — ускорение распознавания прихода v0.2

Это изменение только ЭКСПЕРИМЕНТАЛЬНОГО приложения (пакет com.scansklad.receiptqr.test).
Рабочая ScanSklad v2.0 у сотрудников НЕ меняется.

ПОЧЕМУ РАНЬШЕ БЫЛО МЕДЛЕННО
Когда ML Kit не находил номер, приложение удерживало изображение камеры до окончания двух
проходов Tesseract. В это время камера не могла передать новые изображения на анализ.

ЧТО ИЗМЕНЕНО
1. На каждом кадре первым работает быстрый ML Kit: обычный парсер из ScanSklad v2.0,
   затем геометрический парсер для старого образца (Приход № отдельно от цифр в таблице).
2. Русский Tesseract готовится в отдельном потоке и включается после ~0,38 с,
   только если быстрый OCR не нашёл номер.
3. Для Tesseract делается независимая копия участка внутри красной рамки.
   Кадр камеры сразу освобождается, а ML Kit продолжает работу параллельно.
4. Одновременно работает только один русский OCR; повторная попытка разрешена не чаще
   чем через ~0,85 с. Результаты от старого экрана игнорируются.
5. Проверка двух одинаковых чтений в пределах 1,8 секунды сохранена.
6. QR-адреса, количество (шт./кор/уп), копирование, MAX, НАЗАД/НОВОЕ/ДАЛЕЕ — без изменения.
7. Исправлено подключение Tesseract через JitPack из патча v0.1.1.

УСТАНОВКА ЧЕРЕЗ GITHUB
1. Распакуйте UPDATE.
2. Откройте существующий репозиторий ScanSklad-Receipt-QR-Test.
3. Code → Add file → Upload files → загрузите папку app и файл settings.gradle,
   соблюдая расположение файлов. Commit changes.
4. Actions → Build Android APK → дождитесь зелёной сборки → скачайте артефакт с APK.
5. Установите на тот телефон, где работал предыдущий QR TEST. Если подпись не совпадёт,
   заранее скопируйте сохранённые данные тестового приложения.

ТЕСТЫ НА ТЕЛЕФОНЕ
Новый образец: Приход № 102790; старый образец таблицей: Приход № | 91843.

QR с кириллицей (например 142/П1/1), итоговый список и отправку в MAX.

ВАЖНО
Java-тесты парсера прошли. Android APK ещё НЕ собран в этой среде и скорость/точность
на реальной камере пока не измерена. Работа OCR не может гарантировать 100% точности;
проверка номера перед переходом к QR остаётся обязательной.
