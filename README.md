# ScanSklad Receipt + QR TEST v0.1

**Это ОТДЕЛЬНОЕ тестовое Android-приложение на базе рабочей ScanSklad v2.0.**
Оно устанавливается рядом, а не поверх основной v2.0: package ID `com.scansklad.receiptqr.test`.
Android 8.0 (API 26) или новее. Исходная v2.0 не меняется.

## Что изменено

1. Приход: поиск русской надписи «Приход №» и числа СРАЗУ СПРАВА по координатам OCR. Работает с обычной строкой и с ячейками таблицы — когда надпись и число оказались отдельными OCR-блоками. Длина 4–9 цифр (включая текущие 4, 5, 6 и будущие 7). Одного отдельно увиденного числа недостаточно. Стабильное одинаковое значение нужно получить дважды в окне 1,8 секунды.
2. При отсутствии уверенного результата основного ML Kit на том же выделенном фрагменте запускается дополнительный офлайн Tesseract OCR с русской и английской моделями (`rus+eng`, загрузка при GitHub-сборке). При любом сомнении доступен ручной ввод.
3. Вместо текстового OCR на втором этапе — только QR с обычной текстовой строкой адреса, находящийся внутри красной рамки; QR с интернет-ссылкой не подходит. QR должен содержать, например, `142/П1/1`, `162/шкаф2` или `143/1`. Полученный адрес приводится к принятому виду (без № и пробелов для шкаф/сейф) и проверяется существующим валидатором v2.0. Для других складских адресов сохранён ручной ввод.
4. Количество (шт. по умолчанию, кор, уп), необязательное количество, НАЗАД, НОВОЕ, ДАЛЕЕ, редактирование, накопление, копирование, MAX, локальное сохранение — без изменения логики v2.0.

## Печатные этикетки

`Этикетки_стеллажей_горизонтальные.html` содержит 64 реальных QR-кода из предоставленного списка. В каждом адрес слева, QR справа; при открытии файла не нужен интернет. При печати выберите размер A4, масштаб 100%. Для проверки одной этикетки — `QR_образец_142-П1-1.png`.

Все QR хранят только текст адреса; никакого URL и подключения к сети при сканировании не требуется. Для генерации иных адресов добавлен скрипт `scripts/generate_qr_labels.py` (Python + qrcode): отредактируйте `assets/address_catalog.csv` и запустите скрипт.

## Собрать APK полностью онлайн

1. Создать НОВЫЙ репозиторий GitHub `ScanSklad-Receipt-QR-Test` (можно Private). Не менять работающий `ScanSklad`!
2. Распаковать архив, загрузить ВСЁ СОДЕРЖИМОЕ папки проекта в корень репозитория, Commit changes.
3. Если скрытая `.github` не попала при загрузке: GitHub → Actions → set up a workflow yourself → файл `.github/workflows/build-apk.yml` → вставить полное содержимое `WORKFLOW_ДЛЯ_КОПИРОВАНИЯ.txt`, Commit changes.
4. Actions → `Build Android APK` → дождаться зелёной галочки → Artifacts → `ScanSklad-Receipt-QR-test-APK` → ZIP → `app-debug.apk`.
5. Установить APK на тестовый телефон. Иконка называется ScanSklad QR TEST, приложение не подменяет производственную v2.0.

При сборке GitHub скачает языковые файлы Tesseract `rus.traineddata` и `eng.traineddata` и упакует внутрь APK. После установки распознавание полностью офлайн (отправка в MAX, разумеется, требует интернета).

## Тестирование

Проверьте **на реальных коробках** 4/5/6/7 цифр, оба образца этикеток, разные расстояния и освещение. Номер на отдельной строке или код товара без надписи «Приход №» не должны захватываться. Затем отсканируйте напечатанный QR с кириллицей и 3–4 видами адресов, проверьте итог, копирование и MAX.

Первая Android-сборка и живое OCR на телефоне требуют проверки: чистая компиляция на Android SDK в данной среде недоступна. Модели/настройки могут потребовать уточнений после реальных скриншотов. **OCR не гарантирует абсолютного отсутствия ошибок:** подтверждайте показанный номер прихода до продолжения.
