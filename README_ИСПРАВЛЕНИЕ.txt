# ScanSklad Receipt + QR TEST — исправление сборки 0.1.1

Это исправление **только тестового репозитория** ScanSklad-Receipt-QR-Test. Оно не относится к рабочему Android ScanSklad v2.0.

Причина предыдущей ошибки: Gradle не нашёл зависимость Tesseract4Android версии 4.9.0. Добавлен репозиторий JitPack и использовано альтернативное имя опубликованного артефакта, описанное в обсуждении разработчика https://github.com/adaptech-cz/Tesseract4Android/issues/86 .

Изменены **ровно два файла**:
- `settings.gradle`
- `app/build.gradle`

Откройте тестовый репозиторий на GitHub, вкладка Code > Add file > Upload files, перетащите **эти два файла, сохранив папку app**, подтвердите замену и нажмите Commit changes. Если GitHub не предлагает заменить существующие файлы через Upload files, удобнее открыть каждый из них и отредактировать через карандаш, используя файл из архива в качестве образца.

После commit GitHub Actions запустит новую сборку. Если будет ошибка — отправьте лог красного шага Build debug APK. Сборка APK здесь не выполнялась, поэтому успешную облачную компиляцию подтвердит только GitHub Actions.
