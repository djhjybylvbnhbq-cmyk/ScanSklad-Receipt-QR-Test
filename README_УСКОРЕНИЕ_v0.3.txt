SCAN SKLAD RECEIPT + QR FAST v0.3 — тестовое обновление

Не затрагивает основную ScanSklad v2.0. Пакет тестового APK:
com.scansklad.receiptqr.test. Повышен versionCode до 3.

ЦЕЛЬ
Сохранить скорость на Vivo X300 Pro и улучшить распознавание прихода
на Huawei nova 11i без переключения типа этикетки.

ЧТО ИЗМЕНЕНО
1. ML Kit по-прежнему работает первым и постоянно. Камера отбрасывает старые кадры.
2. ML Kit подтверждается двумя независимыми кадрами за 1,8 сек.
   Для Tesseract и смешанных подтверждений окно — 3,2 сек.
   Повторные результаты одного и того же кадра не считаются двумя проверками.
3. Запрашивается автофокус в центре красной рамки. На рамку или предпросмотр
   можно нажать для повторной фокусировки.
4. Базовое целевое разрешение анализа — 1280×720. Только когда спустя 3 сек
   текст в области рамки остаётся слишком мелким (высота строк меньше 16 px),
   предпринимается попытка повысить разрешение до 1920×1080.
   Если высокое разрешение не поддерживается, приложение пытается вернуться
   к стандартному режиму.
5. Второй, более затратный проход Tesseract выполняется лишь когда
   первый результат пустой или похож на фрагмент этикетки прихода.
6. ДИАГНОСТИКА: долго удерживайте ЗЕЛЁНУЮ ШАПКУ «ScanSklad • QR TEST».
   Откроется окно с моделью телефона, разрешением кадров, временем фокуса,
   числом и временем запусков OCR, числом сбросов распознавания и временем
   до найденного номера. Кнопка КОПИРОВАТЬ копирует эти данные.
7. QR, количество шт./кор/уп, НАЗАД, НОВОЕ, ДАЛЕЕ, MAX, накопление строк
   и ручной ввод не изменялись.

ОБНОВЛЕНИЕ ЧЕРЕЗ GITHUB
1. Распаковать ScanSklad_Receipt_QR_FAST_v0.3_UPDATE.zip.
2. Открыть существующий GitHub-репозиторий ScanSklad-Receipt-QR-Test.
3. Code → Add file → Upload files → перенести папку app из архива.
   Должны замениться существующие исходники; новый ScanConsensus.java
   должен появиться в app/src/main/java/com/labelscanner/offline/.
4. Commit changes. Actions → дождаться зелёного Build Android APK.
5. Скачать app-debug.apk из Artifacts и установить поверх предыдущего
   ТЕСТОВОГО ScanSklad Receipt+QR (тот же идентификатор пакета и больший versionCode).
6. Если Android требует удалить тестовое приложение, сперва сохраните
   список и отчёты. Основное ScanSklad v2.0 НЕ удаляйте.

ПЕРВАЯ ПРОВЕРКА
Одна и та же старая этикетка 91843 и новая 102790,
одинаковое расстояние и освещение на двух телефонах:
Vivo X300 Pro и Huawei nova 11i.
По 10 попыток на каждую этикетку и на каждый телефон.
Записывайте: время (сек.), правильность номера, двигатель (в диагностике).
При нескольких плохих попытках удержать заголовок и скопировать диагностику.

ПРОВЕРКИ
Пройдены чистые Java-тесты геометрии прихода и согласования кадров.
Android APK в текущей среде не компилировался: окончательную сборку и
работу на телефонах нужно проверить через GitHub Actions и на устройствах.
Одинаковая ошибка OCR может повторяться на разных кадрах — перед следующим
шагом сотрудник должен визуально проверить распознанный номер прихода.
